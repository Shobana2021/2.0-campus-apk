# smartcampus (Shobana J)
Front end: index.html, style.css, app.js. Put these on GitHub Pages (Settings > Pages > main > root).
Demo login: shobanaj.bitsathy.ac.in with the password you chose. Demo data is saved in each browser.
Backend (Node.js + Express + PostgreSQL/PostGIS + Firebase) is in the backend folder: run schema.sql, set DATABASE_URL, then npm install and npm start.
Real sign-in needs Firebase Authentication. Maps need a Google Maps API key. Not wired to the front end yet.
